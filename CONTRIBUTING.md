# Contributing to VENOMROSE

Python 3.10+ and standard library only. Keep the unique VENOMROSE identity and preserve the original artwork. Proposed patches should pass `./RELEASE_CHECK.sh` with no internet connectivity. Clearly distinguish indexed listings, reachability and confirmed relay forwarding. Never commit tokens, user reports, browser profiles or personal exports. Avoid automatic proxy rotation, scraping behind login, or claims of anonymity unsupported by measurements.
